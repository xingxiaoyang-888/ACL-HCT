# 修正恢复：诊断干预与HGCN轻量模块

## 2026-09-22：幅度参数化修订完成，超过旧版的目标未达到

研究问题：校准局部几何方向，并让修正幅度保持可训练和采样率响应，能否比旧模块取得更大检索收益，同时保持层级？关系损失是否增加收益？

**结论：本轮“超过旧版”的修订目的未达到；相对未修正采样基座的共同改善仍成立。** 两个固定HGCN、三个预算、两种损失臂的新旧直接比较中，新版的MRR和层级均值均低于旧版；预设MRR优效与层级非劣的Holm24没有一项通过。新版相对S的24项改善全部通过支持家族Holm24，但f4检索观测损失仅恢复3.96%–4.74%，未达20%开发目标。数值正确与有正收益不足以证明这次修订有效。

### 新旧如何公平比较

原有两HGCN骨干和任务头冻结。新版仍454参数、原三个局部方向及10→16→3控制器；将方向按聚合点物理范数校准，采用平滑幅度上限，正则施加于限制前幅度。s=4、tau=.05和其他设置均预先固定。该版本同时改变多个部件，是方法版本比较，不能单独归因于soft-cap、方向单位化或正则。

4个新版训练各1024步，与旧版匹配零输出初始化、训练批次、逐层采样流、开发选模图和选模规则。新选中step为seed11两臂1024，seed23仅任务768、任务+关系256；旧选中分别256/768与256/256。所有候选均保留，没有根据最终结果追加训练或调参。

最终使用独立于旧阶段A及选模的新采样流：2固定模型×3预算×16整图重复×5条件（S、旧/新两臂），共480条件和40个完整邻域控制。每条件8456个完整filtered排名；五条件使用相同图计划。统计单位为每模型每预算的16整图重复，df=15。新随机图没有改变同一开发验证标签的性质，不是独立test。

### 幅度诊断能解释什么

384个新版层级归档的幅度与几何诊断全部有限，最终评价无投影触发，未出现基方向范数小于epsilon的实例。汇总两模型、两臂和16重复的可修正节点实例，第二层平均实际步长/tau在f4/f8/f16分别为0.765/0.558/0.339，平均q弹性为0.386/0.638/0.849；f4最小径向Jacobian约0.00765，最小q弹性约0.0388。说明本次没有旧硬截断下的严格q抵消，但局部仍可接近软饱和。

第二层约35.0%/41.1%/41.8%的控制器系数绝对值达到1.99（上界2）；分母为可修正节点实例的三个系数，并非所有图节点。这是控制器输出接近上界的诊断，不能直接证明其导致收益下降。上述均值按可修正节点实例加权，未将不同图的分位数平均后冒充总体分位数。

本轮否定了“该预设幅度修订已经超过旧模块”的具体期待；没有否定邻居采样造成条件性损伤，也没有否定旧模块的共同改善。减少硬饱和并不自动提高任务效果。方向校准、幅度容量、正则和控制器边界的相互作用仍是候选解释，需要单独设计后续对照，不能从当前版本比较分摊因果贡献。

## 条件定义与部署边界

| 条件 | 含义 | 是否为sample-only方法 |
|---|---|---|
| F / S | 完整邻居 / 原采样模型 | F为完整参照，S为采样基线 |
| O | 在完整参照p的切空间移除独立校准均值 | 否，诊断干预 |
| C | 两层局部聚合应用现有third候选 | 是，但共同恢复未证明 |
| Q | 与O等幅、固定无关方向 | 否，诊断对照 |
| R / T | 只移除径向 / 正交切向均值 | 否，依赖完整p及独立均值 |

O/R/T在末层，C在两层，不能把O/T当C的严格性能上界。径向锚点是固定p[root]，不随条件移动，不是坐标原点。局部切空间正交不保证有限Exp后半径严格不变，R/T效果不能相加成O，也不能分配成几项因果损伤百分比。

## 联合判断：已经证明与尚未证明

| 问题 | 当前结论 |
|---|---|
| 平均方向是否与当前任务损伤有关？ | O优于S和固定Q，支持其在本条件下参与检索损伤；不是全部损失的归因比例 |
| 去掉径向均值是否修复层级？ | 当前R反而显著损害两个模型的父子顺序；不能外推为所有径向调整都无效 |
| T是否共同恢复？ | 两模型MRR改善，但四项层级比较均未通过Holm；不显著不等于无损或非劣 |
| 当前轻量C是否有效？ | MRR均值均提高，仅seed23显著；四项层级收益均未建立 |
| 能否据此宣称通用模块？ | 不能。R/T非部署方法，C未联合通过，且仅一图、两固定模型 |

偏差与中心化随机残差是在指定切空间中的分解；邻居信息减少可以同时产生两者，不是相加为100%的独立第三项。父子相对变化才直接决定间隔变化，单节点偏移变小不能代替关系恢复。原GNN弱于文本MLP的限制仍保留。
