# 修正恢复：诊断干预与HGCN轻量模块

## 2026-09-22：HGCN阶段A完成并独立验收

研究问题：只训练454参数的局部切空间修正器，能否共同恢复成熟HGCN采样后的层级与检索损伤？加入关系间隔损失是否比只用任务损失更有效？

**结论：联合改善获得支持，阶段目的部分达到。** 两个固定HGCN在f4的层级和MRR增益均通过预设Holm24联合标准；只用任务损失训练的模块也获得同样方向的支持。但关系项的额外增益未建立，MRR仅恢复约5.3%的观测损失，未达到双指标各恢复20%的开发目标。实现和本轮结果均已完成验收，不等于整个研究或投稿证据已完备。

### 设计与预设判断

两个既有HGCN骨干/任务头全部冻结，每模型分别训练task-only与task+relation模块1024步，共4组。两臂初始化、批次与采样流配对；模块每层227参数、总454参数，不读取完整参照F或验证层级标签作为推理输入。选模使用两个固定开发采样图、层级门优先且首次严格最高MRR；seed11选中step256/768，seed23两臂均选中step256。保留所有候选和完整训练记录。

最终用全新随机流：每模型16次整图采样、f4/f8/f16、S/task-only/task+relation三个条件，8片共288个条件，每条件8456个完整filtered查询，另有24个完整邻域控制。主家族24个C−S配对检验；关系臂−任务臂另作12个直接比较。统计单位是整图采样重复，df=15，不把节点/查询算作独立训练样本。协议见[阶段A](../docs/operations/RTSC_HGCN_STAGE_A.md)，[机器可读完整结果](rtsc-hgcn-stage-a-summary.json)保留全部效应、边际区间和校正p。

本轮仅能作两个固定HGCN、同一WordNet开发验证标签下的条件性采样结论。最终采样随机流与选模独立，标签集并非独立test；两个骨干检查点也不能证明跨训练种子/数据/架构泛化。仅参数量454已经确定；推理延迟≤10%、训练时间≤15%、显存增加≤10%等相对轻量目标尚未用匹配基线测量。需要保留简单缩放/残差补偿、几何方向与采样系数消融、等时间更多邻居等替代解释，不能把本轮正结果直接当作方法独特性的证明。

## 条件定义与部署边界

| 条件 | 含义 | 是否为sample-only方法 |
|---|---|---|
| F / S | 完整邻居 / 原采样模型 | F为完整参照，S为采样基线 |
| O | 在完整参照p的切空间移除独立校准均值 | 否，诊断干预 |
| C | 两层局部聚合应用现有third候选 | 是，但共同恢复未证明 |
| Q | 与O等幅、固定无关方向 | 否，诊断对照 |
| R / T | 只移除径向 / 正交切向均值 | 否，依赖完整p及独立均值 |

O/R/T在末层，C在两层，不能把O/T当C的严格性能上界。径向锚点是固定p[root]，不随条件移动，不是坐标原点。局部切空间正交不保证有限Exp后半径严格不变，R/T效果不能相加成O，也不能分配成几项因果损伤百分比。

## 联合判断：已经证明与尚未证明

| 问题 | 当前结论 |
|---|---|
| 平均方向是否与当前任务损伤有关？ | O优于S和固定Q，支持其在本条件下参与检索损伤；不是全部损失的归因比例 |
| 去掉径向均值是否修复层级？ | 当前R反而显著损害两个模型的父子顺序；不能外推为所有径向调整都无效 |
| T是否共同恢复？ | 两模型MRR改善，但四项层级比较均未通过Holm；不显著不等于无损或非劣 |
| 当前轻量C是否有效？ | MRR均值均提高，仅seed23显著；四项层级收益均未建立 |
| 能否据此宣称通用模块？ | 不能。R/T非部署方法，C未联合通过，且仅一图、两固定模型 |

偏差与中心化随机残差是在指定切空间中的分解；邻居信息减少可以同时产生两者，不是相加为100%的独立第三项。父子相对变化才直接决定间隔变化，单节点偏移变小不能代替关系恢复。原GNN弱于文本MLP的限制仍保留。
