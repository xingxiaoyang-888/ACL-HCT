## 结果及科学边界

- 原模型、候选修正和 jackknife 均可执行。40节点合成树每方法8步，校正回退率70%、截断率0%。单次 smoke 不支持速度优势或训练效果优势结论。
- 非对称5点、k=3的精确枚举中：局部尺度0.15，偏差范数从7.330e-5降至1.344e-7，但 MSE 从0.00225241升至0.00225634；尺度0.7，偏差从0.00714121降至0.000330949，但 MSE 从0.0501808升至0.0522879。偏差改善不等于 MSE 改善。
- 尚未进行真实数据训练、真实层级坍缩检验、可扩展大图划分或正式统计比较。当前划分工具只用于小图严格泄漏检查。几何工作域与候选局部假设见 README。
- GPU 三方法实测约1.39–1.42秒/方法（包括8步及小图评估），PyTorch 最大 allocated 18,302,976 bytes，reserved 23,068,672 bytes。不是进程完整显存占用，不作生产效率比较。

## 失败记录

1. 服务器直连 Princeton/NLM 下载超时，改为本机从同一官方来源下载后上传；MeSH 使用官方16MB压缩文件。
2. 首次 SFTP 递归传输因目标路径解析失败，改为显式源码 tar 包传输。
3. 首次调度脚本执行受 Windows CRLF 影响，未创建作业；转换 LF 后提交，仓库属性固定脚本 LF。
4. 首次 CPU 作业测试20项通过，但 MeSH 重复树位置校验失败，26秒后 FAILED/1。保留失败记录，增加歧义隔离规则与回归测试后重跑成功。

## 复现

按 README 安装后，`python -m pytest -q`；`python -m acl_hct.smoke --device cpu --output logs/smoke.json`。官方数据先 `scripts/acquire_data.py --download-only`，再在CPU分配中 `--audit-only`。服务器通过 `scripts/smoke.slurm` 提交，显式指定授权资源参数；GPU 设置 `ACL_DEVICE=cuda`，保留 Slurm GPU绑定。

下一阶段需要先审查数据语义、冻结真实层级任务与划分，再决定是否启动新实验。本轮不自动追加计算。
