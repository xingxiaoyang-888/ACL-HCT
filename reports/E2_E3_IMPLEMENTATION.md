# E2/E3 V1 首批 fixture 实现

实现依据父任务冻结的 [V1 决定](../docs/operations/E2_E3_PROTOCOL_DECISIONS.md)。本交付仅包含代码与离线合成 fixture，不开放真实 checkpoint 的诊断入口，不登记真实 R0/R/R_task，不训练或提交作业。N1 单层噪声作为下一次独立提交；当前没有“已缓解层级坍缩”的结果。

`development_view.py` 只读取五个允许的 JSON：manifest、G_obs、训练查询、valid 正关系及实体划分。验证协议、固定实体分组和输入 hash，H_dev 只含 train+valid 正边；不打开 test/truth、文本或特征来派生标签。按可达后代数最大、ID 平局规则选参考根，记录完整候选与覆盖，保留多父最短/最长截断深度和 unknown。超过精确根遍历工作上限就失败，不近似选择根。面板实现冻结的四个随机种子、7个度数层、轮转整数配额、入样概率和池均值设计权重；保留全部直接 valid 父节点及至多4个已证实远祖。无路径不是负例，首轮没有真实异分支指标。

`frozen_forward.py` 在 eval/no_grad 固定模型下缓存完整两层参考，检查权重版本。两层 RNG 子流通过登记 namespace 派生，相互独立；对应条件共享同层计划。显式返回 F/F 的两层、局部 L1、F/S、S/F、S/S；S/F 和 S/S 使用同一真实扰动后的第2层消息场。完整图参与传播，不把 A_f 外误差置零，也不只扰动面板。V/A/P/P_minus_A/V_minus_P 来自固定 G_obs，P 仅称潜在支持。

`frozen_stats.py` 对完整和所有条件统一先检查原生精度约束，再转 FP64 作 Lorentz 归一化，记录约束残差与投影改变量。这只改变诊断表示，原生任务评分不使用投影后的点。另以相同权重/特征转 FP64 完整重跑，记录与原生完整输出的距离、自 Log、Log/Exp 往返和切向内积残差，作为经验数值分辨率代理，不当作严格误差上界。小于该代理的偏差/径向方向保留不可解析标记，锚点重合保留 NA。

共同完整基点上的流式矩报告均值向量、范数、MSE、分母 R 的方差、MSE 分解残差、可为负的噪声扣除平方偏差和独立奇偶半样本交叉内积。组级 MSE/固定方向投影先在每次整图实现内汇总，再计算 MC 标准误，独立样本数为 R。不会跨节点直接平均向量，也不把 R×节点数当样本量。这些 MC 误差条件于当前图/模型/面板，不包含节点抽样设计误差或训练种子不确定性。

`frozen_structure.py` 用完整根表示作所有重复的固定锚点。直接/远祖分开，严格径向顺序得1、完全相等得0.5、逆序得0；保留 ties、正确变错误及错误变正确。先按 child 平均其关系，再用设计权重汇总覆盖 child 的比率；unknown、无关系 child 与权重分母明确报告，该指标不冒称全 V 均值。只利用根可达的 H_dev 正关系，不根据表示好坏删点。确认登记 guard 拒绝缺失完整参照能力、实际损失、独立支持、噪声差异、MC 精度或时间顺序字段；字段齐备仍不等于科学审核通过。

`python -m acl_hct.frozen_fixture --output NEW.json --repetitions 4` 是唯一新增 CLI：固定40节点、4维输入/隐藏、随机未训练权重、f=16，2–16次重复且软时限最多60秒，不接受真实数据/checkpoint 参数。输出图/面板/计划/源码 hash、种子、数值审计、聚合回退/裁剪、结构指标整图 MC 统计及完整 fixture valid 任务统计。最终任务头只用于第2层，始终全部 fixture valid 查询与全部候选；无层1任务假能力或面板替代检索。超时/越域保留失败与完成计数，不重抽或偷偷裁剪。初始化完整参考/数值审计是一个不可打断的小图阶段，后续在图重复和排名 child 边界检查时间。

## 验证
