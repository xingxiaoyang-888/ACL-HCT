# HGCN轻量修正：幅度参数化对照协议

2026-09-22，v1.0，前瞻登记。用户在讨论下一轮设置后明确授权“可以进行你说的新实验”。本轮先完成幅度修订比较；联合训练、HPO、其他数据和骨干不在本轮范围内。代码/数值质量通过后无需重复询问同一实验授权。

## 研究问题与范围

只使用已采样消息及元数据，在两个固定HGCN上，校准几何方向并恢复可训练的修正幅度，能否比原模块取得更大检索收益，同时保持层级改善？关系损失在修订后是否提供额外收益？

旧阶段A已证明条件性联合改善，但f4 MRR仅恢复约5.3%观测损失，未达到20%开发目标；关系损失额外价值未建立。旧硬截断在饱和时令显式q从幅度公式抵消，截断后惩罚无法限制原始幅度继续增长。该数学性质已确认，其对有限收益的因果贡献未确认。本轮同时修订尺度、幅度映射和相应正则，是一个明确的方法版本比较，不把整体收益归因于其中某个单独部件，也不声称无偏。

新增训练为seed11/23 × task_only/task_relation，共4个1024更新。两原始HGCN和任务头全部冻结，模块从与旧版相同的零输出初始化开始；不从旧版训练后修正权重接着训练。原阶段A的配置、源码行为、权重、统计及归档只读保留。

## 固定方法

保留原局部切空间、三个候选方向b1=cVs、b2=cM3、b3=cCs、10个输入特征、10→16→3/SiLU控制器和a_j=2tanh输出；两层共454个参数。插入位置仍为官方HypAgg之后、HypAct之前，使用完整可微的模块Log/Exp。

对每个候选方向按聚合点的Riemann范数平滑校准：

\[
u_j=\frac{b_j}{\sqrt{\|b_j\|_z^2+\epsilon^2}},\quad
q=\left(\frac{N}{N+1}\right)^2\frac{1-k/N}{k},\quad
r=(s\tau)q\sum_{j=1}^{3}a_j u_j,
\]
\[
\delta=\frac{r}{\sqrt{1+\|r\|_z^2/\tau^2}},\qquad
z'=\operatorname{Proj}(\operatorname{Exp}_z(\delta)).
\]

固定s=4，取自本轮训练fanout；这是一次预先固定的数值尺度校准，不按结果搜索，也不随测试fanout改变。tau=.05、epsilon=1e-8（Riemann物理范数单位），与原有数值常量保持一致。零方向仍为零；N=0、k=N、k≤2沿用恒等回退。完整邻域逐节点恒等，不意味着能消除之前层的采样误差。零初始化保持原模型输出且两层输出系数有梯度。

优化的步长项改为逐节点、逐层平均的||r||_z²/tau²；权重仍.001。保留截断后实际步长平方作为独立诊断，不再把它用作幅度正则。关系损失、margin=.1、lambda_rel=.1、训练根和child-macro重要性权重全部沿旧协议。

平方范数直接计算soft-cap，避免在零点先求不必要的平方根。令x=||r||_z/tau，则径向Jacobian为(1+x²)^(-3/2)，固定方向时幅度对q的相对弹性为1/(1+x²)。f4/f8/f16的x上界分别6/3/1.5，对应步长上界约.9864/.9487/.8321倍tau；这是新参数化的明确容量限制。q没有严格抵消，但f4仍可能接近软饱和，因此“梯度非零”或“硬截断为零”均不是充分质量/科学结论。单位化在零附近的导数可很大，须独立检查FP32和FP64的近零行为；如果发生数值失败，保留证据并版本化原则性修复，不能按valid效果调epsilon或s。

## 数据、训练与随机流

沿用[阶段A协议](RTSC_HGCN_STAGE_A.md)的官方HGCN提交、两原始best检查点、WordNet输入清单、82115实体、训练查询与4负例、目标正反边遮蔽、先遮蔽后计度/采样、自环和HT权重、native FP32及已接受的v2数值资格规则。模块不访问完整邻域oracle、真实深度、验证/测试标签或未采样消息。test不加载。

训练设置不变：fanout4，两层128维、c=1、非注意力、无dropout；batch128，Adam lr=.003、weight_decay=0，grad-norm clip1，1024次更新。两损失臂仅差lambda_rel=0或.1。保存step0/256/512/768/1024全部检查点，按原2个开发图、完整8456查询、固定1000-child面板选模；层级相对S不低于-.002的候选中取首个严格最高mean MRR。step0纳入候选，不因正收益不足早停，也不追加更新。

本轮执行协议身份为R-TSC-HGCN-amplitude-v1。module_init、train_batch、train_layer、selection_layer继续使用旧R-TSC-HGCN-stage-A-v1命名随机流，确保初始化、训练批次、图计划和选模机会完全匹配。新类初始化不得因额外构造模块悄悄改变权重；显式比较step0状态、1024批次和逐层plan hash。

final_layer改用新协议名R-TSC-HGCN-amplitude-v1，其余字段和SHA256低63位公式不变。最终16个采样重复与旧96次、旧阶段A最终16图及选模流均分离；五个条件在同一新图上配对。仍是同一开发验证集，新增随机图不等于独立测试或更多独立训练种子。

## 最终配对评价

每个固定模型，在f4/f8/f16各16个新整图随机重复上同时评价五条件：S、old_task_only、old_task_relation、new_task_only、new_task_relation。旧模块从已验收选中CP严格加载，其构造、配置/输入绑定及旧算法行为不能因新实现而改变。旧源码/权重身份和重放数值通过后才使用旧模块作为对照。

按每seed每4重复分为8片，每片60条件，共480条件。每片核验S及四个模块的完整邻域控制，共40个控制；新旧四个选中CP的身份每片一致。完整原始排名、层级、采样计划、点表示和幅度诊断保存归档，便于独立重算。F只作参考，不进入学习。不得只保留对修订版有利的预算或损失臂。

## 预设统计与决策

统计单位为每个固定模型的16个整图采样重复；不把节点/查询当独立重复。以下家族在看新结果前登记，效果与边际95%区间全部报告：

1. **修订是否优于原版：主家族Holm24。** 2模型×3预算×2损失臂，每个对应新旧比较有两个检验：MRR差值大于0的单侧优效；层级差值大于-.002的单侧非劣，共24项，alpha=.05、Student df15。先对层级差值加.002计算非劣p值，再做统一Holm；效应量仍报告原始差值。边界零方差需预先单元测试，不能产生NaN或把不显著下降叫非劣。-.002沿用既有开发容忍度，仅为本轮开发标准，不包装成领域公认阈值。
2. **修订是否共同改善采样基座：支持家族Holm24。** 新模块相对同图S，2模型×3预算×2臂×MRR/层级两指标，共24个原双侧配对Student检验，宣称改善还需均值>0。
3. **关系项额外收益：次要家族Holm12。** 新relation−新task在2模型×3预算×两指标的12个双侧检验；一组显著、另一组不显著不能替代直接比较。

本轮方法修订目的达到的预设条件：至少一种已登记训练臂在两个固定模型的f4同时满足主家族MRR优效、层级非劣，且支持家族相对S的层级和MRR均改善。两臂均预登记并纳入校正，不事后改用某个未登记臂。若仅部分条件成立，报告部分达到/未达到及具体缺口，不以平均两个模型掩盖失败。

20% MRR观测损失恢复仍是独立开发目标，不因旧5.3%结果下调。每个新旧臂都报告(C−S)/(F−S)，仅F−S明确为正时解释为描述性恢复比例；层级超过100%不等于消除了超过100%的因果偏移。f8/f16完整报告，以主家族预登记的同臂层级非劣检验为准，不以“不显著”代替无损。

零方差统一沿用旧协议的保守规则：16个差值完全相同则Student推断记为未定义、p=1、不拒绝，保留原始均值，不生成NaN/无穷或零宽置信区间。即使描述性差值位于容忍范围内，也不据此自动宣称统计非劣；若遇到此情况，如实报告这一验收限制，不临时更换检验。

幅度诊断包括每层每预算的候选方向范数/epsilon作用率、q、系数接近2的比例、raw/step范数除以tau、径向Jacobian和q弹性（至少min/mean/分位数）、两层梯度、投影和回退。记录优化前幅度惩罚与实际步长平方的不同定义；旧版对应可用诊断如实注明，不能伪造旧版未保存的梯度信息。上述诊断用于解释，不替代MRR/层级结论，也不独立证明某一部件的因果贡献。

2. 原服务器环境调度CPU小图，再1张GPU小图；两次分别精确绑定源码/config和独立验收，不能把本机结果冒充服务器验收。
3. 一次seed11/task_relation真实短探针，最多32更新，其权重丢弃。只核验数值、梯度、幅度分布、完整排名、速度和显存，不按valid效果选择公式/常量。旧模块加载/重放也需质量证据。
4. 以上通过后，放行4个新训练；完整性通过后绑定选中CP，放行8个最终分片。科学收益为负不阻止完成已登记比较；数值或来源失败须保留原件、修复复核后续跑，不盲目重抽直到通过。
