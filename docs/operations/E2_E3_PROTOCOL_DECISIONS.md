# E2/E3 首轮开发协议决定 V1

2026-09-16，父监督任务审阅 `reports/E2_E3_PROTOCOL_DRAFT.md` 后制定。本文冻结首轮实现的统计和标签边界；真实诊断仍以完整验证选择的 checkpoint、数值验收和成本登记为前提。不是已完成实验或层级坍缩结论，不改变 S1b 数据、训练及选择协议。

## D1：标签开放范围

采用严格的 train+valid 开发关系视图 H_dev。从训练正查询及 evaluator_valid 生成，绝不在诊断开发器中加载 evaluator_test 或 evaluator_truth。全实体 ID、文本特征、G_obs 和无标签几何统计沿用 transductive 协议。

H_dev 的路径是完整 taxonomy 中确实存在的正路径，但其最短/最长距离不一定等于完整 taxonomy 的距离；没有找到路径不等于完整 taxonomy 中不存在路径。开发阶段不得用缺失路径构造“真非祖先”或用不相交的截断 branch-set 断言真实异分支。

首轮启用直接 valid 父关系、H_dev 中可证实的祖先正路径和无标签几何指标。完整语义深度及真实分支指标暂不启用；这是开发标签的边界，不是将研究问题缩成均值估计。后续可以在独立已知结构协议 A 或封存的正式确认阶段验证完整语义结构，须单独写明标签可见范围。

## D2：锚点与多父深度

模型坐标原点仅用于工程半径统计，不能默认是语义根。首轮径向结构指标使用 H_dev 的一个确定性参考根：从 H_dev 入度为零且有后代的实体中选择可达实体数最多者，平局按稳定 ID 升序。只依据关系，不依据模型半径、准确率或采样误差。记录所有候选数量、选中 ID、可达覆盖率及 H_dev hash。它称“开发关系视图的参考根”，不能称已经恢复完整 taxonomy 唯一语义根。

每层固定锚点为该根在完整 G_obs 前向中的表示；所有随机重复继续使用此完整表示，不随采样移动。锚点重合导致径向方向未定义时保留 NA。根在 valid 中不改变划分，不进入训练监督。

仅对参考根可达实体计算 H_dev 最长路径深度，最短路径及两者差作为补充，均显式标记为截断视图属性。多父边全部保留；根不可达或无可用祖先关系者进入 unknown 组，不能按模型表现删去。全 valid 直接父检索不受此覆盖限制。

## D3：节点与关系面板

几何覆盖率始终报告 V、A_f={N>f}、P_f=A_f 与其一跳消息接收邻居的并集、P_f\\A_f、V\\P_f。P_f 是既有两层模型的潜在影响支持，不表示每个节点实际改变。每个 f 的集合只由 G_obs 决定。局部固定输入诊断可完整计算 A_f 并将其他节点的精确零采样误差纳入全体分母；真实两层传播不得将 A_f 外直接置零。

结构详细面板先将排序的 valid 实体用独立种子 2026091601 置换，前 floor(n/2) 为开发池，其余为诊断确认池。两池都已参与 checkpoint 的完整 valid 选择，不能叫独立任务测试集。每池目标至多 1000 个实体。

主分层为 G_obs 度数 0、1–2、3–4、5–8、9–16、17–32、>=33。V1 不用尚未可靠建立的完整语义深度决定入样；H_dev 深度和 unknown 仅作描述分组。非空度数组按轮转均分整数配额，小组不足则全取并按度数组固定顺序分配余量；层内用种子 2026091602/2026091603 分别 SRSWOR。保存池大小、层大小、入样数、每实体入样概率、清单 hash。平衡面板统计用设计权重还原对应池，不能称全 V 均值。

每个入样 child 保留其全部 direct valid 父关系；额外从 H_dev 可证实的非直接祖先中均匀选至多 4 个，独立种子 2026091604，按 child 等权汇总并报告直接/远祖两组。附加祖先端点不是额外入样 child，不能混改分母。清单在采样结果产生前冻结。无法形成祖先对的 child 仍计入覆盖率。

## D4–D5：传播与零均值噪声

接受 F/F、固定输入局部 L1、F/S、S/F、S/S 的严格区分和配对计划规则。第一、二层随机子流独立；同一次重复中对应传播条件共享同层计划。不得以诱导子图改变真实 N。首轮模型和 fanout 固定为两层、f=16，并有精确 full 参照。

接受 N1：用独立校准重复得到固定切空间残差场，逐节点中心化后，对整个单注入层施同一个随机正负号。匹配的是校准 bank 分母 R0 的经验中心化联合协方差，不是已知真实协方差，也不保持所有高阶分布。保留节点间相关性；逐节点独立符号或独立 Gaussian 不作为等价替代。

首轮仅实现两个噪声条件：L1 注入后经过真实第2层完整传播，与 S/F 比较；完整第1层之后在 L2 注入，与 F/S 比较。S/S 是真实联合传播观察，不声称拥有严格匹配的双层噪声对照，不重复注入端到端第2层总残差。双层条件创新和平行移动留作独立协议，不作为首轮实现阻塞。

可只保存 A_f 的局部残差 bank，其他节点的局部采样残差精确为零；送入下游层时仍形成全图状态，不能只扰动面板节点。统计和矩匹配以 FP64 为准，若为存储转低精度必须记录经验均值/协方差变化。正负成对时整对作为一个独立抽样单位。越域不重抽，不通过静默裁剪维持“匹配”名义。

## D6：统计、结构门槛与措辞

接受共同完整基点 Log 误差、MSE/方差/均值向量范数并报，以及可为负的噪声扣除平方偏差估计和独立半样本交叉内积。组级 MC 误差以整次图随机实现为单位，不能把节点数乘重复数当样本量。方向必须来自解析 oracle 或独立校准阶段，确认数据不得自选方向。

径向祖先顺序评分为严格正确1、完全相等0.5、错误0，同时报告 ties、正确变错误及错误变正确。直接父任务沿用完整 valid、全父候选、过滤其他真父、平均同分秩；面板或16-query probe不得替代完整任务指标。层1不用未经训练的最终关系头冒充层1任务能力。

首轮开发先完整报告参照能力和效应量，不通过任意单一准确率阈值宣布“坍缩”。要使用“层级坍缩”这一结论，必须另完成确认登记：完整参照确有相应结构能力、结构实际损失阈值、独立支持指标、匹配噪声差异以及采样误差精度。该登记必须在确认采样结果和 test 打开前完成。当前允许代码实现和开发描述，不能将尚未登记的阈值当成事后自由选择空间；确认入口应拒绝缺失这些字段的配置。

完整参照的评价不佳时，记录模型能力不足，不能挑层级最差的 checkpoint。任务能力需要与无图文本基线/合理比较对象另作验证，不能仅靠超过随机排序就声称有竞争力。跨训练种子和跨图推广不由固定 checkpoint 的大量采样重复替代。

## D7：数值、成本与分阶段交付

现在批准独立实现和离线 fixture，尚未批准某个 R0/R/R_task 的真实诊断矩阵。先等训练成本及有效 selected checkpoint，再做有限次数的成本/数值 pilot，登记时限、采样子流、R0、确认 R、完整任务 R_task 和有单位的 MC 半宽目标。草案的128/512/2048/8192只是候选，不是默认配额。不能看到确认结果不显著再增加 R。

FP32 输出转换成 FP64 不会自动成为精确的 FP64 流形点。实现必须单独量化流形约束残差、Log/内积数值地板及完整重跑 FP64 对照；如果需要投影，完整参照和所有采样条件用相同明确规则，记录投影改变量，禁止只修某方法结果。小于数值地板的方向/偏差标记不可解析。

首个代码交付优先：固定输入局部统计、配对两层条件、共同基点/流式矩、严格标签加载器、确定性面板、直接父/正祖先指标；附小图独立参考检查。N1 单层噪声可作为下一次单独提交，需检验零均值、节点内/跨节点经验协方差及正负成对统计。不要为未启动的高维全协方差或双层平行移动铺大型框架。

所有开发报告写明计算 commit、checkpoint 选择依据、训练/预处理来源、图与面板 hash、种子命名空间及标签可见范围。保留无效条件、NA、负结果和未完成项。
