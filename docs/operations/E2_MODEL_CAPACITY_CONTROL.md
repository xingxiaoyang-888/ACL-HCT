# E2模型能力对照：有界无图文本基线

状态：2026-09-17主管依据用户“把E2都做完”补齐原详细路线11.1与05节无图文本能力对照的必要准备。先实现及测试，不运行未验收代码。不改变已经冻结的确认登记、模型或70项检验；本对照仅作模型能力描述，不用它选择性保留确认结果。

研究问题：在相同文本、监督数据和有界训练预算下，已有两个双曲GNN的完整valid父检索是否至少有相对于无图文本模型的优势？现有MRR高于随机值或局部顺序较好，不足以回答这个问题。

固定模型为无图MLP：原train-only TF-IDF/SVD的128维特征，两个128维Linear+ReLU层，无图聚合、无归一化层和dropout；关系头采用原协议的[za,zd,za−zd]、128维隐藏ReLU及标量logit，BCEWithLogits。明确这是有界文本能力参照，不是SOTA或严格单因素几何消融。

复用原prepared数据、child分组、固定train正负关系、seed11/23、batch positives128、每正4负、Adam lr0.003、1024步。负例/批次语义应与原训练实现一致，验证只用原全valid/所有实体候选、相同过滤与同分排名。每256步完整valid，选择首次达到最高micro MRR的checkpoint；保存四次全部排名和训练记录。禁止test/truth、改训练步数/选模规则或调超参直到超过某模型。

先审现有API并实现独立模块及配置，保持所有已冻结训练/诊断源码行为；确认仍使用已锁定版本，不因新增模块改变其源码归属。必要测试：模型维度/有限梯度、无图依赖、数据/标签边界、固定负例与批次语义、全候选排名与同分、valid选择、失败停止与来源/权重保存。源码与CPU测试审查后做有界CUDA工程fixture，再两个正式有界训练。

结果仅逐seed对照原GNN四次valid及选定best，报告差值、参数量和成本。n=2不能作训练随机性显著性证明；相同训练步数也不等于相同收敛程度或FLOPs。若文本参照更强，记录GNN竞争力未建立；不自动重训GNN、变更已登记确认或把它改称成功。即使GNN更好，也只支持本对照范围内的优势，不能声称文献最优。

每seed单L40/2CPU16GiB，内3300秒/外60分钟，完整valid单次仍180秒。与确认共享最多4个ACL并发上限，依赖排队而非另加占卡；CVPR两卡保留。无图模型的实际耗时先由工程小样检查，不在此虚构速度。此对照是E2原模型解释的补充，不是E5模块效果实验。
