# R-TSC / HGCN：阶段A冻结骨干训练与验收协议

2026-09-22，v0.1。用户已明确同意研究方案并授权先在HGCN开展轻量模块实验。本文冻结首轮科学设置；实现、源码/配置哈希、实测资源上限及数值质量尚待主管验收后绑定到执行release。不是已经开始训练的记录。

## 问题、范围与交付

在已具备完整邻域任务能力的固定HGCN中，只训练454参数的局部修正器，能否恢复采样造成的层级与检索损伤？关系损失是否改善这种联合恢复？本轮两个旧训练种子仅作为开发检查点，不代表独立训练总体。

执行两检查点seed11/23×两训练臂（task-only、task+relation），共4个1024更新的有界训练。冻结所有HGCN和关系头参数，保留通过其算子的自动微分。完成后以新采样重复评估。阶段B的骨干联合训练、其他骨干、额外数据和HPO不在此release内；它们依已有方案在阶段A交付后具体规划。

依据：[模块方案](../research/04_关系感知轻量切空间修正模块方案.md)。旧96次验证协议、源码、权重、F和数据原件只读保留。实现另建入口、配置与输出目录，不改写旧记录。

## 固定模型、数据与可见性

- 官方HGCN上游固定提交a526385，固定c=1、两层128维、非注意力、无dropout，原任务头不变。
- seed11最佳4096及seed23最佳3584的原权重经旧独立replay验收。训练入口核验权重原始SHA及张量身份，禁止误用last或其他版本。
- 同一WordNet准备目录/输入manifest、82115实体、train正关系、原BCE负例及valid评价规则。不加载test用于训练、调参、选模。
- 每次训练先遮蔽查询正边及反向边，再统计可见度N及按层采样。自环保留，采样权重沿已验收包含概率补偿，不改成样本内普通均值。
- 模块仅取已采样变换消息、自身消息、聚合点、N/k/c及采样元数据。完整F、真实深度、验证/测试标签、历史诊断均值不进入训练forward或目标。
- 训练关系损失只取本批训练正关系；语义根为训练可见taxonomy根，使用当前输出的根表示并detach。完整F固定根只在独立评价分支使用，明确二者参考系不同。

## 方法与训练设置

按研究方案的三方向b1=cVs、b2=cM3、b3=cCs，q=[N/(N+1)]²(1−k/N)/k，10→16→3/SiLU/2tanh系数网络，每层227参数。两层模块置于HypAgg与HypAct之间。输出层零初始化，隐藏层按固定随机流初始化；两训练臂初始模块完全一致。

所有量在聚合点同一切空间计算，使用Riemann度量。模块Log/Exp需完整保留基点梯度，不能直接复用上游含x.data的基点因子；等价公式与原骨干算子分开验证。不得用按学习更新是否为零的提前返回切断初始参数梯度。

N=0、k=N、k≤2按约定恒等回退；不构造D×D或D³张量。τ=0.05，m=0.1；均为本轮c=1的开发参数。新模块epsilon=1e−8，初始chunk_edges=4096；不改变原骨干的投影epsilon，FP64参考须区分稳定化与数学误差。chunk大小仅为执行资源参数，若更改先核验数值等价，不按效果搜索；记录边界投影、步长限制、低k及全邻域回退率。

| 设置 | 值 |
|---|---|
| 训练fanout | 两层各4；相同无放回采样协议 |
| 更新 | 1024，非epoch；每256次选模评价，包含step0 |
| batch/负例 | 128条均匀训练正边，每正例4负例，原任务BCE定义 |
| 优化器 | Adam，lr=0.003，weight_decay=0，只优化模块 |
| 梯度 | 模块总norm clip=1.0；记录clip比例与两层梯度 |
| task-only臂 | 原任务损失+0.001×归一化步长平方 |
| task+relation臂 | 上述损失+0.1×归一化关系间隔损失 |
| 关系损失 | [max(0,(m−g_pc)/m)]²，g_pc=d(r,z_c)−d(r,z_p) |

均匀抽训练正边时，单边关系项乘固定重要性权重|E_train|/(|C_train|×nParents_train(child))后取batch均值，以对应全训练集child-macro目标。不使用batch内自归一替代该目标；train父数只由训练关系计算。任务BCE采样保持不变。

每一步记录训练批次与两层采样的RNG可追溯身份、各损失、有限值、梯度、更新范数、资源。训练两臂共享所有随机序列，模块初始化/训练查询/两层采样/选模采样/最终验收为独立命名随机流。由[protocol,phase,seed,step,fanout,repeat,layer]的紧凑JSON数组（空值null，无空格）做SHA256，取其整数值的最低63位；固定协议名为R-TSC-HGCN-stage-A-v1。生成规则在配置中固定并审计碰撞，不使用Python进程随机hash。

## 选模与最终评估

选模只使用f4的2个固定开发整图采样重复、完整8456查询排名及既有固定1000-child层级面板。每个检查点评价C，并配对同一采样图的冻结S；S可缓存，不能因缓存使用了另一张采样图而失去配对。

合格候选要求两个开发重复的平均直接层级正确率相对S不低于−0.002。合格候选中选平均完整micro MRR最高者，平局首次优先；step0也在候选内。训练完整1024步，不因早期收益停止。不合格或最终选中恒等step0均诚实报告，不能换规则挑模型。保留全部检查点评价和无约束最高MRR作为描述性记录，不替换主选模。

最终采用独立于旧96次及选模流的16个整图随机重复，在f4/f8/f16上配对评价S、C_task、C_relation。按每模型4个重复一片分成8片，每片36个条件输出，总计288个。各片核验相同选中检查点，并对基座和两个模块的完整邻域前向分别按已接受v2规则核验固定F；局部k=N严格恒等，但不同GPU稀疏前向不要求逐位相等。F不用于模块学习。一次采样计划可复用于三个条件，以减少重复采样开销；各条件推理输出必须独立保存并核验。

主家族：2个固定模型×3个预算×2个模块臂×2项指标，共24个C−S配对均值检验，Student df15，统一Holm24、alpha=.05。主指标为完整filtered micro MRR与直接父child-macro层级顺序正确率。所有效应、边际区间及校正p保留，不把节点/查询当独立图重复。C_relation−C_task的12项比较列为独立次要家族Holm12，不因“一组显著另一组不显著”推断两组不同。

联合恢复主判断：f4下C_relation−S在两个固定模型的两指标都为正且通过主家族。20%双指标损失恢复是开发实用目标，同时报告绝对收益；恢复率仅在当前F−S明确为正时给出描述性比例，不解释为因果占比。f8/f16方向与区间完整展示；本轮暂不作正式非劣声明，避免把不显著误报为无损。远祖/分支、误差矩与方向为辅助诊断，不替代主指标。

## 必须先过的质量门

1. 独立小图CPU检查：切空间/Riemann范数、Log/Exp及零位移导数，有限值，k=N/低k/零分散；梯度对FP64参考/有限差分。
2. 模型入口：零初始化与原HGCN输出和损失一致；冻结参数hash不变，系数输出层首步可学习，两层模块梯度通；HypAct之后仍有可测响应。测试不能靠直通估计器掩盖公式错误。
3. 信息边界：训练关系、degree、采样及目标边遮蔽；固定parent-count权重；模块禁止oracle/测试输入。
4. 原服务器运行时CPU小图回归，再1张GPU小图回归。native FP32、原投影规则；FP64仅作明确参考，不把整个旧骨干double()后当同算子。
5. 一次真实数据短性能/梯度探针（不超过32更新，独立临时模型、不进入1024步结果），检查首次/末次梯度、冻结权重、峰值显存、吞吐及完整排名。探针不进行超参数挑选，其权重不作正式初始化。

质量失败保留原件，先修复及复核，再绑定新源码版本；不通过反复抽样直到通过、改结果阈值或重选种子解决。若数值门需因训练输出范围变化而调整，须先解释量纲/运行时依据并版本化，不能把精度问题转为效果调参。
