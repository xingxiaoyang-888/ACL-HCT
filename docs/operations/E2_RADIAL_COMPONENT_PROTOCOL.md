## A：已有存档的关系间隔定位

令固定参考根 r=p[root]。每条原面板关系 (parent,child) 在条件 X 中的间隔为

`g_X = d(r,X_child) - d(r,X_parent)`。

逐 seed、重复、条件保存父/子径向距离、相对 S 的变化 delta_parent/delta_child，并核对恒等式 `g_X-g_S = delta_child-delta_parent`。F 固定；主要观察 O、C，Q 作为已存在的方向参照。保存 S→X 的正确/错误/平局完整转移，以及 F→S/F→X 转移；不只选择 F 原本正确的关系。基于 F 正误的分层可作解释，但保留总体。

逐关系原始数据与逐子节点汇总同时保留；总体顺序指标继续使用旧 child-macro 加权口径，避免多父节点获得额外权重。原总体指标必须复现，unknown 和数值未分辨关系计数必须复现。

在看新分组结果前固定分组：

1. 子节点原 degree strata：0、1–2、3–4、5–8、9–16、17–32、33+。
2. 子节点原 h_dev_shortest：0、1–3、4–7、8–15、16+、unknown。
3. 参考间隔：先分 F 正/负/平局；另按 `abs(g_F)` 分组。`abs(g_F)<=原pair resolution` 单列未分辨，其余在同模型同关系类型的固定参考关系中取25/50/75分位点；NumPy linear quantile，重复边界合并，不拆相同值。
4. 子节点旧校准偏移范数：零值单列，其余在固定面板子节点中取25/50/75分位点，同样合并重复边界。

分组结果为探索性描述：给原始关系数、子节点数、原权重质量、完整转移、间隔变化及每重复变化，不把节点/关系当独立训练样本，不做大量子组显著性筛选。只作单因素分组，不自动扩成交叉矩阵。

按节点ID对齐保存的检索排名与面板；保留完整检索总体，并明确交集覆盖。记录每个可对齐子节点的 child-macro reciprocal-rank 改变量及层级变化，呈现同升、同降和相反变化。不能用交集替代完整 MRR，也不据相关性宣称因果。

交付：机器可读完整摘要、可追溯逐关系/子节点结果、少量解释性图表和简短结论。判断目的是否达到，看能否定位翻转来自何种父子相对移动、是否集中在低间隔/某些固定组；没有集中规律也如实报告。

## B：两项方向分量干预

对于每节点固定基点 p_i、参考根 r，定义 `v_i=Log_{p_i}(r)`。当其径向方向可分辨时，取向外单位切向量 `u_i=-v_i/||v_i||_L`，使用洛伦兹切空间度量投影：

`b_rad = <b,u>_L u`，`b_orth = b-b_rad`。

仅增加 R 与 T 两个条件：

- R：`Exp_p(Log_p(S)-b_rad)`；只移除径向平均误差。
- T：`Exp_p(Log_p(S)-b_orth)`；只移除正交切向平均误差。

根或与根过近时径向方向不可识别。预先固定判据：`d(p_i,r) <= max(floor_i+floor_root,1e-10)`。这些节点 R/T 均直接复制原生 S，保存 undefined 标记及未施加的 b；不删除节点或改变评价分母。分解恒等式在方向可识别节点验证，不能把未识别部分假称为已分解。O 在这些节点原有行为保持历史记录，涉及 O 的解释须注明差别。

这只是固定局部切空间的正交分解。有限 Exp 移动后，T 不保证全局半径完全不变；R/T 的任务效果也不必相加等于 O。实际径向变化和方向变化作为辅助诊断保存，不能把两者写成独立可加的损伤比例。

R/T 无可调缩放、无符号选择、无阈值搜索、无新增随机流。F/S/O/C/Q 均沿用旧已验收档案。对原同一个 S 生成 R/T，冻结关系头执行完整 filtered validation 排名，保留所有节点、查询和原结构覆盖。
