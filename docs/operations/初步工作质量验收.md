# 初步工程质量验收

本清单由论文/监督任务制定，用于审查实验任务的交付。测试应检验数学与数据性质，而不是复述实现。检查均通过仍不意味着科学假设已成立。

## 数学与数值

- 明确曲率参数 c>0 对应截面曲率 -c、Lorentz 坐标顺序及内积符号。所有几何操作支持声明的 batch 形状和 dtype；非法曲率与无效输入不能静默产生似是而非的输出。
- 在 CPU FP64 参考上检验流形与切空间约束、Log/Exp 互逆，以及零切向量、重合点的正确极限。避免仅靠 clamp 在零点制造非零距离或掩盖约束失效。
- 检查 autograd 在零/小范数处及非退化随机点的有限性；在平滑的非退化点比较解析/自动梯度与独立有限差分。注意 where 的未选择分支若含除零或无效运算，仍可能污染反向传播。
- 在声明的工作半径内比较 FP32 与 FP64，而不是用过宽容差遮盖误差。超出稳定区间要有诊断，不对全局大半径任意裁剪后宣称等距不变。
- 检验完整聚合的邻居排列不变性、同点一致性、正权重共同缩放不变性。自环、重复边、空邻域必须定义清楚。

## 采样与候选修正

- 可复现的随机数生成器应显式传递；不通过重置全局 seed 使所有节点意外得到相同抽样轨迹。
- 无放回采样的选中邻居无重复；小有限总体通过枚举/频率检查分布，完整采样与完整聚合一致。N 是实际可见候选消息数，不能用全图节点总量。
- 候选三阶矩修正 k=N 时应严格退化；k=1、2、N<3 和空/低度邻域采用明确回退，禁止直接除以零。局部不对称性必须参与方向估计。
- 对小型非对称邻域独立枚举所有子集，与既有 NumPy 参考对照；明确曲率、N/k、局部离散尺度及修正符号。不把偏差降低设为所有分布上都必须通过的断言。
- 在有反射对称性的总体上核查期望偏移的对称性；大分散和小 k 场景记录方差/MSE 的可能恶化。偏差和 MSE 分别汇报。
- 记录修正步长、回退与数值保护触发率。完整邻域 oracle 只可进入评估器，不能偷偷用于构造部署修正项。

## 数据与层级诊断

- 记录每个下载的官方来源、源版本/日期、下载时间、大小和 SHA256，并将许可入口保存到 manifest。SHA256 是取得文件的完整性记录，不能替代官方来源校验。
- 解析使用本地小 fixture 测试，覆盖多父关系、孤立节点、重复边、缺失字段等真实边界。解析输出统计与官方格式/合理计数相互检查。
- 将语义层级真值与消息图分开；验证/测试待预测关系及反向边/泄漏闭包不可进入训练图。对根、DAG 深度与分支指标给出明确语义。
- 仅在有层级真值时报告层级损伤；半径统计、几何偏移及标签预测精度各自命名，不能互相替代。

## 部署与验收证据

- 远程目录、环境、缓存、数据及日志归 ACL 独占；提交脚本接受显式资源参数，保留调度器 GPU 绑定。只读记录其他作业存在与分配情况，不操作其进程。
- 数据与依赖就绪后申请首个单卡短作业。记录 JobID、状态、退出码、实际设备、环境版本、命令、commit、峰值显存及用时；释放后复查队列/历史。
- 仓库中提供可重复执行的命令，默认测试无下载副作用。公开报告不包含凭据、服务器私有连接信息或原始数据包。
- 本地通过与远程通过分开，运行成功与研究有效分开；若某项未实现或受队列/网络限制，明确标记而不自动宣布全部完成。
