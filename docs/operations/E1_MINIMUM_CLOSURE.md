## 2. 简单缩放对照：先固定操作，不挑最佳系数

对原采样聚合Y，定义坐标原点o_c下的

Y_scale = Exp_o_c(alpha * Log_o_c(Y)), alpha = 1 + lambda * (1/k - 1/N)。

lambda固定为-1、0、+1，分别报告收缩、恒等和扩张；不是从结果中选择赢家。系数只依赖N/k，曲率通过几何映射进入，不使用总体p、oracle偏移或局部三阶矩。对k=N恒等，k=1/2也照定义计算，不冒称候选修正的低k回退。越域显式失败，不暗中裁剪系数。

这是一个有限、固定的简单尺度对照，不是“所有尺度方法”的最优实现，也不据此声称压倒经过公平调参的缩放基线。未来E5若比较经调参的缩放，须在允许开发集单独登记相同预算。

## 3. 零均值匹配噪声：精确总体oracle诊断

本补充所有配置继续exact枚举。共同完整基点p上，原聚合残差为xi=Log_p(Y)，精确总体均值mu=E[xi]；对每个子集残差e=xi-mu，等权保留+e和-e，得到Exp_p(±e)。

这个oracle中心化对照在FP64误差内零均值，协方差等于原残差的中心化总体协方差，分母为精确子集总数；它不保持全部高阶分布，不使用未中心化二阶矩冒称协方差。矩阵和径向/横向投影分别核对。正负两次是一个配对构造，不能伪作两份独立MC样本；此处exact，无MC标准误。

该对照依赖总体信息，只能用于机制诊断，不能进入sample-only候选模块。其MSE等于原方差、偏差为零是构造恒等关系，不是研究发现或方法优越性证明。它也不能替代真实图中的独立校准、跨节点相关噪声及传播对照，后者仍保留为后续N1工作。

实现先做一遍精确均值，再按相同子集顺序生成中心化场，记录两遍一致性。对所有条件采用同一几何域规则，不因越域重抽。简单缩放及此噪声补到原54条件；原始结果保持，新增结果独立保存。
