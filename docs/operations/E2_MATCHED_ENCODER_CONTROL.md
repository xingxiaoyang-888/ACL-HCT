# E2 匹配编码器的无邻居对照 v1

2026-09-17，协议名 `E2-matched-encoder-control-v1`。研究问题：**保持原径向编码器和关系头时，将邻居聚合替换为自身消息，是否改变当前WordNet父节点检索能力？** 这是定位图聚合路径整体作用的探索比较，不是纯曲率消融、部署修正效果或原E5。

目的：补上原GNN与ReLU MLP比较的混杂，选择下一项有依据的骨干修查，为“采样偏移—层级损伤—轻量修正”主线提供可靠基础。结果尚未产生，当前不能预写改善。

不改变原确认矩阵或旧GNN/MLP结果；不追加原模型训练，不新增seed、学习率/半径搜索、test读取或E3–E5。后续新关键实验另行形成方案与用户同意。

## 唯一架构变化及公平条件

- 原 `LorentzMeanNetwork` 两层Linear、径向映射、exp/log与关系头全部保留；各节点在每层接收自身的原消息，不接收其他节点消息。新模型与原模型全空邻域的self fallback路径应数值等价。
- 保留参数名称、张量形状、构造随机数顺序和参数量82433。原环境同seed构造及历史MLP对应初始张量hash作为核对依据；原GNN未保存初始快照，不能冒称与其历史快照直接比较。
- 允许只编码本批唯一查询实体以节省计算，但必须检查索引回映，并与全实体原self fallback的输出、BCE、全部参数梯度比较。无跨节点运算、归一化或dropout，不新增可训练参数。
- 图仍用于原输入契约核验，不进入新模型的消息路径。去掉图路径也去掉其采样随机性，差值只能解释图路径整体作用，不能分解为单独的采样或确定性混合效应。

## 数据、训练、选模与比较

复用原prepared：manifest `b5fc4847260854e5401ffe0d5111f32b7d1138f1de5d11c881e2d4c312c25473`，valid query hash `7fa4f51d558393d69a523bccb9f21527805409e1ea914377141ce02fdce584eb`；128维train-only文本特征，原child分组及固定训练负例。只允许读取既定train/valid输入，不打开test或完整truth。

两seed固定11、23；128正例组×每正4负，平均BCE；Adam lr=0.003，1024更新步，原CPU batch RNG为seed+1，每步randperm后取128组。逐步索引hash与原MLP历史全部1024步对齐，batch流与CUDA工程fixture的随机数分离。

第256、512、768、1024步各一次完整valid，全部8456查询、全部实体候选、原过滤及精确同分平均排名规则。保存完整排名，选择首次达到最高micro MRR的checkpoint；不增加选模机会。记录各相同步、各自best的micro/macro MRR和Hits@10、训练曲线、参数/输入身份、实际资源及失败。

预先固定主读数为各seed新模型best micro MRR分别减原GNN和原MLP best；同时完整给出四个固定步骤的差值，不能只挑一个有利比较。父degree0、1、2–16、>16的分组只作为预先指定的定位读数，按原未遮蔽图和原query身份计算，报告计数与整体贡献，不做额外确认性检验。

两个训练seed只作描述性比较，不给训练随机性的显著性结论。同参数/步数不等于同FLOPs、训练时间或充分收敛，valid也不是独立测试集。新对照不参与修改已完成的E2确认结论。

## 质量和停止门槛

1. 旧科学源码原字节保持；新配置与执行相关源固定hash。原prepared、历史run、原初始化构造和1024步抽批流完整核对，缺少或冲突即停止。
2. 独立小图FP64数值/梯度检查；原2.5.1 CUDA FP32比较原self fallback、全实体新路径与唯一实体新路径，logit/损失/全部参数梯度使用 `atol=2e-6, rtol=2e-5`。测试同时覆盖有限值、流形、排名与同分、缓存失效、保存/重载、错误来源/授权/非有限结果拒绝。GPU未通过不得训练，不通过先调查而不放宽容差。
3. 真正训练必须完成1024步及四次完整valid；部分valid不得选best或继续冒充完整结果。所有应有参数梯度和权重有限，标签仅用于允许的训练/评价位置。
4. 两份best的保存后重载核验含权重hash、训练/选模元数据以及原完整valid排名复现，不能只复算已存排名摘要。结果方与主管分别核对原始证据和关键结论。
5. 配置漂移、输入/批次hash错误、非有限值、超时、缺失步骤或排名触发明确失败并保留证据。作业使用外部进程硬截止，不只在step边界检查时间；失败成本计入本轮上限。不得用同一输出目录覆盖失败。

科学结果为正、为负或混合均可完成本对照目的；“程序通过”不等于“图混合已证明有害”。若两seed新模型均优于原GNN，只能支持本预算下图路径不占优势；若方向混合，明确证据不足；若仍落后MLP，编码器路径仍是待隔离因素。每一种结果均先报告，不自动扩展训练。
