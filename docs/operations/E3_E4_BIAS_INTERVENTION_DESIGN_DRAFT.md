# 偏移是否损伤层级：冻结干预设计草案

2026-09-17。**仅设计，尚未登记样本数、骨干版本或预算，未启动科学实验；不能视为E3/E4通过或用户已批准该阶段。** 当前先完成已授权的匹配编码器对照。

研究问题：在固定模型和固定采样预算下，移除采样误差的平均切向分量，是否恢复层级关系与检索表现？若恢复，效果是否优于等幅但不对应偏移方向的变化？这一步连接“有平均偏移”和“有层级损伤”，也决定是否值得继续把该分量近似成可部署的小模块。

## 明确观察量与诊断干预

令节点v的完整推理输出为p_v，第r次采样输出为h_vr。在固定的T_{p_v}中定义 `e_vr = Log_{p_v}(h_vr)`。用独立校准采样重复估计 `b_v = E[e_vr]`，评价重复不能参与该均值估计。模型权重、任务头、查询集合、图、采样预算和结构定义保持不变。

最小对照考虑：

| 条件 | 输出 | 要回答的问题 |
|---|---|---|
| 完整推理 | p_v | 完整可见邻域的固定参照 |
| 原采样 | Exp_{p_v}(e_vr) | 本批原采样损伤；先验证与原输出重构一致 |
| 移除平均偏移 | Exp_{p_v}(e_vr−b_hat_v) | 平均分量的移除能否恢复信息？ |
| 反向干预 | Exp_{p_v}(e_vr+b_hat_v) | 放大同方向平均分量是否更差，或出现不符合假设的例外？ |
| 等幅无关方向 | Exp_{p_v}(e_vr−q_v) | 相同幅度的移动是否已经足够解释收益？q_v长度匹配b_hat_v，方向由独立固定规则产生 |

q_v须在该节点切空间中生成并归一化，不能直接把环境坐标中的随机向量当切向量；b_hat_v为零时q_v也为零。条件共享评价采样实现，不能各挑最好重复。系数、方向和干预位置不在评价结果出现后选择。

固定减去b_hat只平移该切空间中的误差样本，因此中心化残差及其协方差保持。它不保证exp之后的距离分布、流形方差或层级结构保持；这些正是需要测量的结果。校准均值本身有误差，需要独立半样本/方差估计检查精度，不能把估计太噪导致的不恢复直接判成“真实偏移无作用”。

## 能支持的结论与不能支持的结论

主读数仍是直接层级关系指标，并辅以任务排名、偏差/方差/MSE。结构与任务分开判定，不要求它们机械同向。不使用半径变化代替结构。已有参考根覆盖不足时，保留unknown分母，并在新登记中补充可行的分支/非单根结构证据。

若移除偏移较原采样稳定改善结构，且优于等幅无关方向、与反向干预形成合理区别，可支持“该平均分量在此模型、预算、干预位置下对损伤有贡献”。它仍不是普遍因果定理，更不证明全部采样损伤都来自偏差。若结构改善而任务不改善，分别报告；若均不改善，先核校准精度与对照有效性，再重新评价机制假设。

结果按相同固定采样重复做配对统计；先用既有方差资料规划重复数和精度，再冻结主比较和多重检验家族。两模型的重复采样不是更多训练seed，验证集也不升级为独立测试集。恢复比例仅在完整与采样存在明确非零差距时才有解释力，分母接近零时报告原始差值。

## 与轻量模块的关系

该干预使用完整推理表示和大量校准采样，是**机制诊断oracle，不能部署**。只有这一步显示值得恢复的方向成分，才继续检验能否用采样邻域统计、degree、采样量与曲率近似该方向和幅度；完整邻居表示、完整oracle均值和测试标签不能输入实用模块。

末层输出干预先回答“已有表示能否被这样恢复”，不等于局部逐层修正可实现，也不替代原E3深度、无采样深层与噪声对照。后续需明确模块落在第几层、哪一个切空间、如何随传播变化，并分别衡量近似误差、结构/任务收益和计算成本。

正式执行前必须完成：依据匹配对照确定并冻结可信骨干；选择结构面板与覆盖口径；冻结校准/评价随机流、预算/重复数、误差精度和主比较；实现数值与方向控制并独立验收；给用户可审查方案并取得该关键阶段同意。
