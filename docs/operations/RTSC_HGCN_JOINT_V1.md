# HGCN匹配联合训练：六条件开发实验协议

2026-09-23，v1.0，前瞻登记。协议身份`R-TSC-HGCN-joint-v1`。用户在阅读六组方案后明确回复“可以，进行实验”，授权本轮必要实现、质量检查、短探针、12组训练、配对评价、匹配成本测量和独立验收。通过本轮工程门后不重复索取同一实验授权。旧幅度修订已经结束，其结束边界不取消本轮；CVPR专属指令不自动适用于ACL。

## 研究问题与可支持范围

在相同采样、训练机会和关系监督下，旧版三方向切空间修正是否比经过采样训练的普通HGCN提供额外的层级/检索收益？该收益是否优于只沿自身消息方向的简单修正？关系监督在各结构中的作用是否一致？

这是两个既有完整邻域预训练检查点出发的有界联合微调开发实验。它可检验匹配训练后的模块增量，不单独证明冻结训练是旧收益受限的唯一原因，也不证明从头训练或跨训练种子/骨干/数据的泛化。16次采样是同一已训练模型下的条件性重复，不是16次独立训练。原20%冻结模型恢复目标仍未达到；本轮不通过更换分母将其改记为通过。

已有阶段A及幅度修订的源码、配置、权重、数据、失败与结果只读保留。旧科学源码以`c822b8af284b22bf9ad0c4d891afd12f3ffa0b94`及之前的分阶段绑定为准；本轮另外实现、配置、命名随机流、release与输出。新私有根`.local/rtsc-hgcn-joint-v1`。不训练幅度修订版，不做HPO、其他数据/骨干、增加训练种子或下一方法变体。

| B / plain_relation | 普通HGCN，无修正模块 | 0.1 |
| C / three_task | 旧版三方向修正 | 0 |
| D / three_relation | 旧版三方向修正 | 0.1 |
| E / single_task | 单方向修正 | 0 |
| F / single_relation | 单方向修正 | 0.1 |

两个起点仍为seed11的原best4096和seed23的原best3584，使用成熟HGCN独立replay已验收的原始检查点身份。每起点六组都从相同骨干/任务头张量开始，不能从旧训练后模块或某个联合训练组继续训练另组。模块输出层为零，每个起点和层的共同10→16隐藏层初始化完全匹配，单/三方向输出分别为1/3且均为零。普通组没有占位可学习参数。

所有组骨干和原任务头均可训练；模块组同时训练其修正器。固定c=1、两层128维、非注意力、无dropout、同一官方HGCN上游a526385和原有向任务头。不更换激活/曲率/采样定义。旧原始模型是输入谱系，不再是训练期间冻结权重；本轮不能误用“冻结参数必须不变”的旧训练验收。

## 单方向对照的精确定义

沿用旧三方向模块在聚合点z的局部Log、Riemann度量、10个标量输入、几何统计、采样系数q与回退规则；旧模块本身不修改。

三方向为b1=cV Log_z(x_i)、b2=cM3、b3=cCs，δraw=q Σ_j a_j b_j。单方向只使用b1，δraw=q a b1。其系数网络为10→16→1、SiLU、a=2tanh，与三方向的10→16→3配对隐藏层初始化。单方向每层193参数，两层386；三方向仍每层227、两层454。真实报告参数差，不声称精确等参数。它仍保留相同几何特征，包括用于标量特征的M3/Cs信息，因此检验的是额外候选向量方向的价值，不能称“去掉所有高阶信息”。

两种模块均采用旧版Riemann硬步长上限tau=.05：δ=δraw min(1,tau/||δraw||_z)，随后Exp_z与原manifold投影，置于HypAgg与HypAct之间。q=[N/(N+1)]²(1−k/N)/k，epsilon=1e−8，默认chunk_edges4096。步长正则保持旧版限制后||δ||²/tau²，权重.001；不混入幅度修订的方向单位化、scale4、soft-cap或raw惩罚。保留硬饱和与梯度诊断，其存在不自动判失败，也不证明因果机制。

N=0、k=N、k≤2及零离散沿旧实现恒等/零修正规则。完整邻域每层的模块严格恒等；局部全邻域不保证没有前层误差。所有模块只读取采样消息与元数据，不读取完整F、根ID、真实深度、valid/test标签或跨重复oracle均值。

## 数据、目标及训练设置

保持原WordNet输入manifest、82,115实体、67,539训练正关系、128维train-only文本特征和既有child分组划分。训练查询正边及反向边先遮蔽，再计算可见度N、无放回选邻居和HT包含概率权重，自环保留。负例仍每正例4个，仅按训练真父过滤。valid完整filtered排名与关系面板规则不变；test不加载。

| 项 | 固定值 |
|---|---|
| 更新 / fanout | 每组1024更新，两层f4；不按最终效果延长或提前停止 |
| batch | 128个均匀训练正关系，各4负例 |
| 优化器 | Adam，betas(.9,.999)，eps1e−8，weight_decay0 |
| 学习率 | 骨干及任务头3e−4；模块3e−3，无学习率调度/搜索 |
| 裁剪 | 所有可学习参数合并grad-norm clip1.0；另记各参数组裁剪前梯度及更新 |
| checkpoint | step0/256/512/768/1024全部保存；包含优化器状态与完整随机流记录 |
| 任务损失 | 原BCE定义，各组完全相同 |
| 关系损失 | 原margin=.1的归一化平方hinge，lambda=0/.1按臂固定 |
| 步长损失 | 模块组旧限制后归一化步长平方×.001，普通组为0 |
| 精度 | 已资格的native FP32；几何不使用混合精度；独立FP64参考注明适用边界 |

关系根仍来自train-only可见taxonomy，使用当前采样前向的根表示并detach；每训练正边按|E_train|/(|C_train|×nParents_train(child))作固定重要性加权，对应child-macro目标。不以batch自归一替代。训练关系损失与下面评价锚点是不同对象。

本轮全新命名随机流，以紧凑JSON [protocol,phase,seed,step,fanout,repeat,layer]的SHA256低63位生成。phase至少分module_init、train_batch、train_layer、selection_layer、final_layer、benchmark；六组的同起点训练批次和图计划完全相同，名称不包含结构/损失臂。两层独立；训练/选模/最终/成本分流，不能复用旧科学图作为新确认。初始化中构造不同模块不能暗中改变基础权重或后续随机流。

## 各检查点的完整参照与公平选模

联合训练后，各组都必须建立自己的full参照，不能与旧原始F逐值比较并要求不变。

每个候选检查点保存当前权重、完整邻域native点、完整排名和数据/采样/来源身份；以其本身无修正full前向为F。模块在full下数学恒等，模块on/off控制用来核验这点，不生成额外完整邻域训练目标。两臂/六组的F不同是允许的，不代表六种数据输入或六种层级定义。

评价根节点ID、关系对、child权重、unknown/tie规则和1000-child面板沿既有冻结定义，绝不按效果重选。每个检查点的评价锚点固定为**该检查点full中的同一根节点表示**，在它的所有采样预算/重复中保持不变。比较不同训练组时，根ID相同而各自full根坐标可不同；这样不把不同训练产生的坐标漂移误当关系损伤。不能为每张采样图移动评价根。

选模：同起点六组共用2张固定f4开发图，每个候选完整评价8456 queries。初始无修正S0在这2图上的直接层级均值作为共同门槛，候选自己的固定full锚点评价的层级均值不得低于S0−.002；合格候选中取首个严格最高mean micro MRR。step0纳入、平局先到者优先，五个候选必须齐全。所有组拥有同样门槛和选模机会。无合格候选或选step0如实记录，不改规则。S0使用初始模型自己的full根，不把旧根坐标用于新模型几何。

候选full与选中检查点的fresh重载须逐项核对身份、点、内点/有限值、双曲距离、排名、层级gap/order；原v2数值限值先作为预设工程门应用于**同一新检查点自己的参照**，不冒充在所有新权重上已校准的误差定理。来源/权重/图/候选分母严格相等；不得通过投影/裁剪改写raw后验收。若新的权重范围使门失败，保留原件，独立核查数值原因并版本化原则性修复，不放宽门槛去迎合采样效应。既有原始起点仍须通过原v2绑定资格。

## 最终评价与归档

每起点的六组训练完整且选中CP均独立验收后再放行该起点最终评价。每个起点×f4/f8/f16×16张新图×六条件，合计576个采样条件。同一(起点,fanout,repeat)下六组使用相同图计划，但各自加载各自训练后的权重/任务头。每条件保存完整8456 query排名、8210 child汇总、native坐标、层级关系指标和模块/数值诊断，不只保存均值。

按起点×repeat_start(0,4,8,12)分8片，每片72个采样条件。每片检查6个选中CP的full资格；四个模块组另外各有full module-off控制，共每片10个完整控制、总80个。各组F与该组训练保存的选中参考绑定，各片共享同组固定参照，不能将full控制当独立统计重复。身份、阶段随机流、六条件计划配对和去重均须审计。

诊断保存直接/远祖顺序、MRR/hits、F−S绝对差、训练与选择曲线、模块步长/硬截断/投影/回退、基座/任务头/两层模块的梯度与更新。目的在解释，不以训练loss、参数变化或更少截断替代科学收益。

## 预设统计与目的判断

统计单位为每个已训练组在同一起点与预算下的16张配对整图重复，Student df15、alpha=.05。所有效应及边际双侧95%区间完整报告，区间不是同时区间；两个起点分别判断，不将它们的图重复合为独立训练种子。零方差按旧保守规则：p=1、区间未定义、不拒绝，保留均值。

1. **f4主家族Holm16。** 2起点×2损失臂×4项：三方向−普通的MRR单侧优效>0、层级单侧优效>0；三方向−单方向的MRR单侧优效>0、层级单侧非劣>−.002。具体为C−A、D−B、C−E、D−F。层级NI的p值按差值+.002计算，效应和区间仍为未平移差值。两损失臂均预先登记，不按最终结果增加臂或只选有利起点。
2. **f8/f16保护家族Holm32。** 2起点×2预算×2损失臂×2对照(普通/单方向)×2指标。MRR NI界限−.0005、层级NI界限−.002，均单侧。原始效应、区间、是否出现下降同时报告；不显著不是非劣。两容忍量沿研究方案的开发建议，仅是本轮开发界限，不声称领域公认阈值。
3. **关系项家族Holm36。** 2起点×3预算×3结构×2指标，B−A、D−C、F−E作双侧直接检验，按效应符号解释。没有校正后证据不能称等效；同样不以一组显著另一组不显著推断交互作用。

分开报告目的：

- 模块增量目的：至少一个相同预登记损失臂在两个起点的f4上，相对匹配普通HGCN的两指标均为正且通过主家族。
- 额外方向价值：同一臂在两个起点还须相对单方向对照MRR优效、层级非劣通过主家族。只满足前项时，模块增量有支持，额外方向价值未建立。
- 跨预算保护：对上述臂的f8/f16保护家族逐项报告；没有全部通过就不能宣称预算迁移无损，不隐去负结果。
- 关系监督价值独立按Holm36判断，不强行要求完整关系臂必须获胜。单方向对照同样好时，保留简化方向而非把复杂性当证据。
- 20%冻结模型恢复目标保持旧未达结论。本轮报告各组自身F−采样的差和匹配训练组间绝对收益；不把联合训练后的不同F拼成旧(C−S)/(F−S)恢复率。若描述各组自身采样损失，明确条件和符号，不作平均偏移的因果占比。

本轮所有最终科学家族只在8片齐全并独立原档验收后计算。不用最终图挑CP、决定步数、学习率或再搜新变体。开发选模标签与最终标签相同，新图并非独立test。

## 匹配成本测量

完成选模后，在单GPU、相同设备/运行时/CPU配额内，分别对两个起点的六组执行独立成本phase；不以不同并行节点上的训练日志直接得出开销结论。固定f4和相同训练批次/采样计划，预热5次、交错顺序测量20次。使用权重/优化器副本，基准更新不保存为科学CP，不反向改变选模。记录同步计时、峰值allocated/reserved显存及实际设备占用。

推理至少分别报告编码器前向和含完整排名的端到端成本，不能用排名的大分母掩盖模块的编码器开销；采样计划构建/数据搬运单列。训练记录前向、反向、optimizer与总步时，固定输入计划的核心时间及真实采样流水时间分别说明，禁止省去只在某种结构存在的工作。主要轻量判断使用匹配编码器推理、完整训练步和峰值显存；完整排名成本辅助报告。目标沿原方案：相对同监督普通HGCN，推理≤+10%、训练≤+15%、显存≤+10%，模块<1000参数。未达到则仅可称参数少，不宣称运行代价轻量。超出1000-query/缓存等不一致设置不得混作匹配比较。
