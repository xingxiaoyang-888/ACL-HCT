# 初步工作范围与验收

日期：2026-09-16。本文是本次启动的执行约定；与历史实验矩阵冲突时，以本文的初步工作范围为准。

## 研究主线

工作题目：**When Sampling Breaks Hierarchy: Tangent-Space Correction for Hyperbolic Graph Neural Networks**。

研究问题：邻居采样何时使双曲消息传递产生方向性偏移，进而系统性损伤深度和分支关系；能否由曲率、采样覆盖率及邻域统计推导轻量切空间修正，在固定采样预算下改善结构与任务表现？真实网络中的层级坍缩尚待验证，不能预写为结果。

已有资料仅提供研究设计和候选局部公式：归一化 Lorentz 聚合、均匀无放回采样、局部邻域、小曲率尺度等假设要逐一核查。`research/legacy/numerical_check.py` 是既有玩具检查，不是通过审查的正式实现，也不代表已完成新实验。没有要求锁死三阶矩候选公式；先建立可检验的算子、指标和公平对照。

## 本次交付

1. 单一、可同步的代码仓库；清楚的 README、安装方式、配置与数据目录结构。
2. 与其他项目隔离的远程目录、Python 环境和依赖版本记录；GPU 仅通过 Slurm 申请，记录实际 L40 型号与环境。
3. 可审查的初始模块：Lorentz 几何、完整/采样聚合、可复现邻居采样、候选切空间修正接口、合成层级图与结构诊断；必要时包含小型 GNN 基线和训练入口。
4. 有意义的单元与集成测试，覆盖几何不变量、数值和梯度、无放回采样、完整采样一致性、k=1/2 回退、数据解析/划分无泄漏、确定性小规模端到端运行。默认测试不依赖网络或大数据。
5. 官方数据拉取与审计脚本，以及实际取得的首批层级数据。优先 WordNet 与 MeSH；记录版本、URL、许可说明、SHA256、节点/边/层级与度数摘要。MeSH 源文件较大时保留断点续传。后续 Amazon/OGB 根据机制证据再扩展，不默认下载整个评论库。
6. 一次有上限的 CPU/单 GPU 初步验证，产生结构化日志、峰值显存和实测时间。原模型与修正接口均需可执行，但正收益不作为允许交付的前提；失败和无效条件照实记录。
7. 在 `reports/STATUS.md` 中区分已实现、已测试、已部署、已排队、已完成与阻塞；将可发布的代码和摘要同步至 GitHub。

## 计算预算与执行顺序

先准备依赖和数据，再申请 GPU。首个 GPU 验证最多一张、30 分钟；成功后释放资源。使用基准测量估计后续成本，不能把此前的 455-run 上层规划作为自动执行清单。双卡/八卡只用于后续明确需要的并行任务，当前保留 CVPR 所需资源。

推荐顺序：仓库与部署脚手架 → 环境和数据准备 → CPU 参考及核心测试 → 冻结算子/小图诊断 → Slurm 单卡 GPU smoke → 汇报实测资源和下一阶段建议。数据采集与不依赖数据的代码编写可并行推进。

## 科学验收边界

- 保留“采样诱导层级坍缩—几何机制—轻量修正”的研究问题，不因启动规模较小而改成只有均值估计偏差。
- 数值通过不等于机制成立；小图成功不等于真实网络层级坍缩；更小偏差不一定意味着更低 MSE 或更好任务效果。
- 固定模型的多采样率诊断可复用 checkpoint；不同训练采样率或改变训练图必须按新训练配置处理。
- 未采样邻居表示、测试层级标签或完整 oracle 输出不能成为部署修正器输入。完整邻域只用于参考与诊断。
- 历史文献表是研究背景，不是已完成的新颖性审查；实现时依赖和 API 以实际环境及官方资料为准。
