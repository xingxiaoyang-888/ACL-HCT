# 关系感知轻量切空间修正：HGCN首版方案

日期：2026-09-22。状态：用户已同意本方案并授权先在HGCN开展模块实验；首轮阶段A正在实现和质量准备，训练尚未启动。具体首轮设置以[阶段A协议](../operations/RTSC_HGCN_STAGE_A.md)为准，后续阶段参数仍需具体化。本文是方法方案的统一入口，不另建同问题进度稿。保留原01/02路线及已验收协议；对原路线的具体修订如下。

## 1. 研究问题与本轮目标

**研究问题：有限邻居采样损伤双曲GNN的关系表达时，能否只利用已采样消息与采样元数据，通过小规模切空间修正，同时恢复层级结构和下游任务效果？**

成熟HGCN的96次验收已支持：两个固定种子在f4均发生层级与检索联合损伤，所有三个预算的检索下降稳定；较宽松预算的层级损伤不一致。问题具有开展方法研究的实证基础，不需要再把主要精力放在旧诊断模型的MSE或R/T分解上。尚未证明平均偏移解释全部损伤，也未证明所有骨干或所有预算均发生层级坍缩。

本轮方法目标为：**采样信息决定何时及多大程度介入；局部几何统计提供候选方向；训练关系和任务损失决定怎样组合这些方向。** 部署时不查真实父子标签，不访问未采样隐藏消息或完整邻域正确输出。

暂称R-TSC（Relation-aware Tangent-Space Correction，关系感知切空间修正），只是工作名称，未作名称唯一性或方法新颖性认证。

## 3. 模块插在哪里、看什么

当前官方层实际流程为HypLinear → HypAgg → HypAct。首版设为：

```text
同一邻居采样及权重
    → 官方HypLinear（得到消息x）
    → 官方HypAgg（得到当前聚合点z）
    → R-TSC（已采样消息的局部统计 → 小系数网络 → Exp_z更新）
    → 官方HypAct
    → 下一层 / 原有关系打分头
```

两层各放一个模块、参数独立；不增加图传播层，不增加邻居，不更换曲率、ReLU或任务头。首版固定c=1、128维、非注意力，与已验收骨干一致。仅末层的插入位置作为成功后的定位消融，而非现在搜索许多位置。

每个节点每层可读取：当前输出z、变换后的自身消息x_i、本次k个非自身邻居消息、遮蔽目标边之后的可见候选度N、实际k、曲率c、已知采样概率与权重。N不是完整真值图度数；训练查询的正边及反向边继续先遮蔽再计算N和采样。

训练关系只供损失函数读取。模块forward不接受根ID、真实深度、测试父子边、完整F点、跨重复估计的均值误差、节点ID嵌入表或历史完整邻居缓存。第一版不训练完整邻域教师，不做隐藏状态蒸馏；F只在独立评价分支使用。

## 4. 一个具体、可编码的首版

### 4.1 共同切空间与局部统计

记当前聚合点为z，非自身采样邻居集合为S。所有向量均放在T_z，内积、范数使用对应黎曼度量；Poincaré坐标中的普通Euclidean范数不能直接代替它。

\[
v_j=\operatorname{Log}_z(x_j),\quad
\bar v=\frac1k\sum_{j\in S}v_j,\quad
e_j=v_j-\bar v,\quad s=\operatorname{Log}_z(x_i).
\]

计算三个量：

\[
V=\frac1{k-1}\sum_j\|e_j\|_z^2,\qquad
M_3=\frac1k\sum_j\|e_j\|_z^2e_j,\qquad
Cs=\frac1{k-1}\sum_j e_j\langle e_j,s\rangle_z.
\]

V是邻居离散程度；M3表示局部分布不对称性；Cs表示邻域沿“聚合点到自身消息”方向的分布形状。实现Cs只需逐消息内积及归约，不构造D×D协方差，更不构造D³三阶张量。

使用三个候选方向：

\[
b_1=cVs,\qquad b_2=cM_3,\qquad b_3=cCs.
\]

它们依次表示“离散程度调制的自身位置调整”“不对称性调整”“局部各向异性调整”。这些方向均由本次可见局部几何产生；没有预先规定一律往外推，也没有把径向/正交分解当创新。它们是**待验证的候选方向空间**，不是已经证明包含真实偏差方向的完备基。

### 4.2 采样强度系数

对当前必选自环、均匀无放回非自身邻居协议，采用：

\[
q(N,k)=\left(\frac{N}{N+1}\right)^2\frac{1-k/N}{k}.
\]

依据是：对固定输入的原点切空间消息，完整均值的估计器为
\(\hat u=u_i/(N+1)+[N/(N+1)]\bar u_S\)，其采样协方差恰为q乘完整非自身消息的有限总体协方差（分母N−1）。这给出一个明确的采样尺度依据。

**界限：q的这项恒等式不等于整个非线性HGCN输出偏差公式；随机基点z上的V/M3/Cs也不是上述完整协方差的无偏替代。** 将q用于这里是有依据的设计选择，组合方向、符号和幅度仍需学习、比较及理论审查。

### 4.3 极小系数网络

每层使用10→16→3的MLP，共227个参数，两层共454个。隐藏层SiLU，输出为三个有符号系数a=2tanh(MLP(f))；最后一层权重和偏置初始化为零，使模型从原骨干开始。

10个标量输入：log(1+N)、k/N、log(1+k)、log(1+c)、log(1+cV)、log(1+c||s||²)、log(1+c||v_bar||²)、标准化三阶矩大小||M3||/(V^(3/2)+epsilon)、cos(s,M3)、<s,Cs>/(||s||²V+epsilon)。零范数时角度项定义为0，数值epsilon随已冻结的实现约定设置，不用测试结果调它。

候选更新为：

\[
\delta_{raw}=q\,(a_1b_1+a_2b_2+a_3b_3),\qquad
z^{corr}=\operatorname{Exp}_z(\delta).
\]

δ为对δ_raw施加黎曼步长上限后的向量。建议开发默认上限τ=0.05/√c；是否合适要由训练稳定性和验证集检查，不能称为理论最佳值。上限防止一次局部修正过大，并记录触发频率；它不保证任务一定改善。

首版k≤2回退原输出，避免把极小样本高阶统计当可靠信号；N=0、k=N直接返回原输出，V=0时修正为零。完整图每一层都无采样时，模块严格恒等。某层局部k=N不代表该节点已不受前层采样影响；首版不会在该层额外修补继承的误差，这是需要报告的覆盖边界。

模块复杂度为O(kD)加固定小MLP；流式或分块归约避免物化整个图的边×维度副本。但比原点切空间的稀疏聚合多了逐边Log，因此**454个参数不意味着速度开销天然很小**。速度、显存、反向图存储和额外几何投影都须实测。

## 5. 为什么“关系感知”必须体现在训练目标中

设语义根为训练可见taxonomy中的已知根节点，r为其本次前向表示，损失计算时对r停止梯度。对训练可见的有向父子关系(p,c)，定义：

\[
g_{pc}=d_{\mathbb H}(r,z_c)-d_{\mathbb H}(r,z_p),\qquad
\mathcal L_{rel}=\operatorname{mean}_{child}\operatorname{mean}_{parent}
\left[\max(0,(m-g_{pc})/m)\right]^2.
\]

这是保护相对关系间隔：孩子相对根应比父亲更远，并保留适量余量。父节点外移比孩子更多时，即使二者的单点误差都下降，间隔仍可能受损；这正是旧诊断告诉我们的教训。

建议m=0.1/√c作为开发启动值；多个父节点采用child内归一，不让多父child占更多总权重。只使用训练正关系和训练可见祖先闭包，未知关系不伪装成负例。首版先用直接父关系训练；远祖顺序、分支/同级区分与完整检索共同评价，研究对象不因此限定为父子排名。

r来自当前可见模型前向，不来自完整F或测试标签；不新增根的邻居查询。原点不自动等于语义根。训练使用当前根而冻结诊断使用固定F根，因此报告分别写明参考系；最终层级评价对同一比较始终固定参考，不用移动评价根制造改善。根不可达、unknown和零距离关系按冻结规则标记，不填造深度。

联合损失：

\[
\mathcal L=\mathcal L_{task}+\lambda_{rel}\mathcal L_{rel}
+\lambda_{step}\operatorname{mean}_{i,l}\|\delta_i^{(l)}\|^2/\tau_l^2.
\]

L_task沿用相同MLP关系头、BCE及每正例4负例；L_rel旨在减少任务提升时的层级破坏，不能保证每条关系恢复；L_step仅抑制无必要的大更新。开发起点可用λ_rel=0.1、λ_step=0.001，上式关系损失已经按m²归一，不再重复归一。系数/上限的最终值只由训练稳定性和开发验证选择。

“关系感知”在此准确指：**系数学习接受关系级监督，并由局部几何统计区别调整各节点**。推理时没有真实父子查询或全图关系修复步骤，不保证每条关系都保持。若相同局部统计无法区分需要相反修正的语义角色，局部模块会存在表达边界，不能事先承诺通用恢复。

## 6. 训练顺序：先证明模块有效，再允许骨干配合

### A. 冻结骨干与任务头，只学模块

使用已验收seed11/23检查点作为开发起点。骨干及任务头参数冻结，模块从零更新开始；训练输入只使用训练关系及采样消息。仍保留梯度穿过冻结的后续层和任务头，不能用整段no_grad阻断前层模块学习。

首个有界开发条件为f4，两层同预算；每模型建议先运行1024次更新、每256次完整valid检查，batch/负例规则与原训练一致。相同初始点比较“模块+任务损失”和“模块+任务及关系损失”；另保留恒等S/F作评价参照。该阶段回答在不改变骨干能力时，修正本身能否同时改善指标，不承担最终泛化证明。

必须比较全量valid MRR，不能用训练BCE或小候选排名代替；每个候选checkpoint按固定开发采样种子评价。选模规则预先写明：先满足层级非劣约束，再在候选中选择MRR最高者；不存在合格者即记录失败，不挑一个表面较好指标交付。固定种子仅供选模，验收使用新采样随机种子。

### B. 匹配的联合训练：四组核心对照

从同一对应初始检查点出发，允许骨干和原任务头一起训练；所有组共享训练步数、数据、采样序列、评估机会和调参额度。

| 组 | 模块 | 关系损失 | 要回答的问题 |
|---|---|---|---|
| A | 无 | 无 | 原采样骨干适应训练后的水平 |
| B | 无 | 有 | 单加关系监督已经能解决多少 |
| C | 有 | 无 | 模块对任务自身是否有价值 |
| D | 有 | 有 | 完整方案是否超过相同监督的B，并取得联合恢复 |

阶段A时骨干冻结，给“无模块”模型加损失没有可学对象，因此不能在那里冒充训练对照；完整2×2矩阵放在本阶段。真正关键比较为D−B，而不仅是D−A。

首轮仍是两个开发种子的短预算；通过后再冻结正式训练与HPO计划。正式结论至少增加独立训练种子（建议5个）及未触碰test，并做从头匹配训练，避免最终方法只依赖完整邻域预训练起点。不同训练种子是泛化统计单位；每检查点16次采样只能估计条件性采样波动，不能当16次独立训练。

### C. 有收益后补最必要的替代解释

依次加入：相同输入的小参数径向缩放、合理适配的几何jackknife、匹配参数与步长预算的普通残差模块、与新增运行时间相匹配的更大fanout。特别检查去M3、去q、固定系数和仅一层模块。早期四组失败时先分析方向空间/损失/梯度与开销，不自动扩出大矩阵。

训练f4后测试f4/f8/f16及完整邻域；不为每个测试预算重新调系数。之后再讨论混合训练预算、MeSH及第二骨干；不把现有HGCN方向与q直接宣称适用于注意力或有放回采样。

## 7. 联合验收：先冻结，再看收益

以下为建议开发验收标准，尚未授权执行或宣称其为学界通用阈值。

1. **质量门**：零初始化等同原模型；k=N恒等；流形合法/有限值；小图梯度与FP64参考；无监督泄漏；相同采样权重；冻结参数不变；梯度确实流向两层模块。检查修正在HypAct之后仍有实际作用，不能只测激活前的坐标变化。原精度及数值重放策略保持，不能因新模块失败而改宽阈值。
2. **主科学门**：预先确定f4为已知联合损伤条件。D−B的完整MRR与直接层级顺序两项均为正，并通过预登记的多重比较。冻结模型开发阶段两个种子分别报告，不合并掉失败者；联合训练正式阶段按独立训练种子做配对统计。
3. **实用目标**：建议f4至少恢复20%的层级和MRR损失，作为开发目标而非已证保证。冻结模型可用同一F/S/C计算(C−S)/(F−S)，仅在F−S明确为正时报告；同时报告原始绝对差和区间，恢复率不能替代显著性或因果解释。联合训练每组F会变化，必须报告D−B绝对收益及各自采样损失，不能直接套旧F比例。
4. **其他预算**：原本层级损伤不明确的条件以非劣检验为辅。建议讨论冻结容忍幅度为层级0.2个百分点、MRR0.0005；只有适当校正后的置信界超过负容忍界才可称非劣，“不显著下降”不算。若接受范围缺乏应用依据，应优先报告精确区间，而非自动通过。
5. **轻量门**：建议目标为推理延迟增加≤10%、训练时间增加≤15%、峰值显存增加≤10%，参数<1000；相同设备、warmup、同步计时并报告分布。达不到应如实改变“轻量”的表述，不能只凭参数少验收。新模块还需超过把同样时间用于多采邻居的基线。

冻结阶段如仍采用2模型×3预算×2主指标，继续登记完整Holm12，不只挑f4显著结果报告。非劣、多方法比较及正式训练种子的统计家族需在各自协议中单列清楚。模型选择数据与最终评估分开，旧96次只用于问题发现/设计，不再称新方法的独立确认。

## 8. 理论如何服务方法

已经可写清的部分是固定线性消息估计的协方差缩放q。对非线性输出，局部思路为以完整μ为中心展开
\(\Psi(u)=\operatorname{Log}_{F(\mu)}F(u)\)，领先均值项涉及\(\tfrac12 D^2\Psi(\mu):\operatorname{Cov}(\hat u)\)，再研究三阶项、ReLU分段边界及多层传播。此处只是推导路线：需小邻域、光滑区域和同算子假设，不能把展开式当全局纠偏保证。

本设计用三个局部统计方向和系数学习承接这些机制线索；不能未经推导声称它等于上述Hessian收缩项。若HGCN的解析展开给出更简洁、可核验的系数，可将其设为初始化/纯解析对照，再测试学习是否必要；无需为了先训练原型而编造闭式定理。旧Lorentz三阶矩分支独立保留。

## 9. 文献定位及潜在贡献

- [HGCN，Chami等，NeurIPS 2019](https://arxiv.org/abs/1910.12933)：提供双曲变换/聚合及层级表示基础。我们的官方非注意力路径已在本地固定源码核对，不能从HGCN论文本身推断邻居采样必然造成坍缩。
- [Pennec，2019](https://arxiv.org/abs/1906.07418)：分析小样本、高集中度下流形经验均值的矩及曲率影响。均值定义与假设必须对应；其结论不是当前HGCN的直接修正系数，也不能推出常负曲率下任何均值都有同样方向的偏差。
- [TOP，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/32c2f3e0a44d55820da7fbcee0a1d95c-Paper-Conference.pdf)：以消息不变性和线性变换补偿批外消息。说明采样补偿并非新概念；本候选需要证明“受采样尺度调制的局部几何修正＋关系/任务联合恢复”有独立价值，而不只是又一个补偿网络。

以上为本次方案的定向依据复核，不是更新完毕的近一年综述或首创性证明。投稿前需再核对近期几何校准、图采样补偿及关系正则近邻。

潜在贡献应落在：在明确条件下识别关系损伤，构造部署可用且受局部几何约束的小修正，验证其在相同监督、采样及时间成本下恢复结构和任务。不把“加一个MLP”“加一个margin loss”或R/T分解本身包装成新贡献。
