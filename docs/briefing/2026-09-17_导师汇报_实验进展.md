# 采样诱导的双曲表示偏移：实验进展

状态：主管维护的汇报草稿，依据2026-09-16已验收记录；真实基线与后续诊断结果到达后更新。下文明确区分完成、观察与待验证。

## 一分钟开场

我们研究邻居采样是否会在双曲图神经网络中引入有方向的几何偏移，以及这种偏移能否经过传播损伤层级关系。候选方案是利用切空间局部统计做轻量修正。目前受控实验已观察到可预测的方向性偏移，修正降低了偏差，但也增加了均方误差，因此真实网络中的结构与任务收益仍需验证。实现、数据准备和单卡训练路径已跑通，并完成一次保持训练结果一致的效率优化。

## 研究问题与证据链

核心问题：采样产生的方向性几何偏移，是否会在真实图传播中系统性削弱已有层级信息；轻量切空间修正能否在偏差—方差交换下改善结构或任务表现？

证据顺序为：实现正确性 → 受控方向性偏移 → 真实模型固定权重诊断 → 真实结构损伤及噪声对照 → 修正干预与端到端效果。当前不能跳过中间环节，由“减小偏差”直接推出“缓解层级坍缩”。

## 已完成与主要观察

| 工作 | 已验收内容 | 含义与边界 |
|---|---|---|
| E0 | 78项CPU测试、78项真实CUDA检查 | 支持已测范围内几何、采样、批处理、梯度实现正确，不是研究效果 |
| 首轮E1 | 54条件、138483个邻域精确枚举 | 对称构型平均偏移接近浮点零；反向非对称构型的偏移反转 |
| 候选修正 | 在非对称及反射组的18个有效配置中降低偏差，同时提高MSE | 必须保留偏差—方差交换，不能宣称全面改善 |
| WordNet准备 | 82115实体、128维文本特征、67539训练正关系 | 按child分组；文本仅在train拟合；G_obs只含train边及反向 |
| 真实训练路径 | 单L40原配置10步完成，loss和全部参数梯度有限 | 仅工程试跑，尚不证明收敛或竞争力 |
| 等价效率优化 | 同卡第2–10步均值8.275秒→2.330秒；最终训练状态一致 | 本次观测约3.55倍，单次固定old→new顺序，不是统计稳定速度结论 |
| 显存 | PyTorch peak allocated约1.601GiB，reserved约1.719GiB | 当前两层128维配置的分配器峰值，不是所有未来实验或整GPU进程占用 |

E1中尺度0.7、k=3的例子：原偏差范数0.004977，未裁剪修正后0.000137；与此同时MSE约增加5.76%。这是受控构型的结果，不是真实网络损伤或收益。

正式G_obs在fanout16时，直接发生采样删减的节点占约0.758%，移除约10.73%的消息。少数高连接节点贡献较多消息，但这还不证明其扰动会传播成层级损伤。后续同时报告全体、直接受采样影响节点及潜在传播范围。

## 正在进行

- 完整验证评估：入口已实现；无Git归档的测试fixture身份问题正在修复，尚未执行真实完整valid。
- 有界基线训练：计划两个种子并行、每个最多1小时，完整valid选择checkpoint。配置发布和评估门槛通过后才运行。
- E2/E3：首轮开发协议已审，代码fixture在实现。开发只用train+valid关系；全语义深度/分支不能由未开放test关系偷偷派生。

## 当前不能声称的结论

尚未证明真实网络出现系统性层级坍缩；尚未证明修正提高真实结构或任务效果；尚未建立多种子稳定性或模型竞争力。10步probe结果不是完整验证，也没有产生best checkpoint。
