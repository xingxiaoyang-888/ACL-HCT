# 采样诱导的双曲表示偏移：实验进展

状态：主管维护的汇报草稿，依据2026-09-16已验收记录；真实基线与后续诊断结果到达后更新。下文明确区分完成、观察与待验证。

## 一分钟开场

我们研究邻居采样是否会在双曲图神经网络中引入有方向的几何偏移，以及这种偏移能否经过传播损伤层级关系。候选方案是利用切空间局部统计做轻量修正。目前受控实验已观察到可预测的方向性偏移，修正降低了偏差，但也增加了均方误差，因此真实网络中的结构与任务收益仍需验证。实现、数据准备和单卡训练路径已跑通，并完成一次保持训练结果一致的效率优化。

## 研究问题与证据链

核心问题：采样产生的方向性几何偏移，是否会在真实图传播中系统性削弱已有层级信息；轻量切空间修正能否在偏差—方差交换下改善结构或任务表现？

证据顺序为：实现正确性 → 受控方向性偏移 → 真实模型固定权重诊断 → 真实结构损伤及噪声对照 → 修正干预与端到端效果。当前不能跳过中间环节，由“减小偏差”直接推出“缓解层级坍缩”。

## 已完成与主要观察

| 工作 | 已验收内容 | 含义与边界 |
|---|---|---|
| E0 | 78项CPU测试、78项真实CUDA检查 | 支持已测范围内几何、采样、批处理、梯度实现正确，不是研究效果 |
| 首轮E1 | 54条件、138483个邻域精确枚举 | 对称构型平均偏移接近浮点零；反向非对称构型的偏移反转 |
| 候选修正 | 在非对称及反射组的18个有效配置中降低偏差，同时提高MSE | 必须保留偏差—方差交换，不能宣称全面改善 |
| WordNet准备 | 82115实体、128维文本特征、67539训练正关系 | 按child分组；文本仅在train拟合；G_obs只含train边及反向 |
| 真实训练路径 | 单L40原配置10步完成，loss和全部参数梯度有限 | 仅工程试跑，尚不证明收敛或竞争力 |
| 等价效率优化 | 同卡第2–10步均值8.275秒→2.330秒；最终训练状态一致 | 本次观测约3.55倍，单次固定old→new顺序，不是统计稳定速度结论 |
| 显存 | PyTorch peak allocated约1.601GiB，reserved约1.719GiB | 当前两层128维配置的分配器峰值，不是所有未来实验或整GPU进程占用 |

E1中尺度0.7、k=3的例子：原偏差范数0.004977，未裁剪修正后0.000137；与此同时MSE约增加5.76%。这是受控构型的结果，不是真实网络损伤或收益。

正式G_obs在fanout16时，直接发生采样删减的节点占约0.758%，移除约10.73%的消息。少数高连接节点贡献较多消息，但这还不证明其扰动会传播成层级损伤。后续同时报告全体、直接受采样影响节点及潜在传播范围。

## 正在进行

- 完整验证评估：归档fixture问题已修复。原10步checkpoint的8456/8456条valid查询均完成，编码+排名约27.64秒；micro MRR约0.00185035，Hits@10约0.00603122。没有选择或写入best，checkpoint哈希未变。主管已独立核对原始结果与两类源码哈希、查询数量、排名范围，并重算MRR；这是10步模型的开发结果，不能作为收敛或竞争力证明。
- 有界基线训练：seed11/23均完成原定1024步，各4次完整valid，资源已释放。两者best均为step768，micro MRR分别0.01753685/0.01392854；末步回落为0.01612680/0.01121512。主管独立核对原始文件/源码/配置，并从全部8次排名重算micro及child macro MRR。合计5118 GPU秒（1.42167卡时）；并发耗时不作为无争用速度对照。末步第二层近参数化边界比例77.33%/72.15%，属于重要混杂因素，不能归因为采样层级损伤。
- E1补充：已完成102条件、435561个exact子集；816个方法结果均通过预定数值审计及主管独立来源复核。实际CPU 2核作业82秒、0 GPU。54个非对称及镜像有效记录中，三种修正均减小偏差，但52个增大MSE、2个减小MSE；镜像不是独立重复。seed23有限尺度斜率从原偏差约三阶变为三阶矩修正后约五阶，支持局部理论预测，不是渐近证明或整体收益证据。
- E2/E3：已有协议与工程代码保留，真实实验尚未启动。须先完成E1质量与科学解释审查，再取得用户明确同意；开发只用train+valid关系。

## 当前不能声称的结论

尚未证明真实网络出现系统性层级坍缩；尚未证明修正提高真实结构或任务效果；尚未建立多种子稳定性或模型竞争力。10步probe不用于模型选择；随后对其last做完整验证也不追认该模型为best checkpoint。

## 资源与下一步

已知本阶段已完成分配成本：真实训练恢复及其失败/诊断合计128 GPU秒，旧新实现同卡验收140 GPU秒，完整valid评估40 GPU秒，双seed基线5118 GPU秒；小计5426 GPU秒，约1.5072 GPU小时。这不是整个项目累计费用，未包含更早的其他历史运行。CPU工作单列，不能当GPU卡时。

完整valid成本测量已获执行回报，两个种子的有界基线按原范围收尾；当前优先补齐E1。后续固定checkpoint的局部/两层传播诊断须单独经过质量、预定指标与用户批准，不能自动推进。真实图噪声对照拟保留单注入层的节点间经验协方差，以区分方向性偏移与相关随机扰动；模型本身需要先具备可测的结构能力。
